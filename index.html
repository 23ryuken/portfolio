I’m Eric Mbithi. I build full-stack apps from database to interface.

I trained at Moringa School and build mainly with the MERN stack: MongoDB, Express, React and Node.js, adding PostgreSQL when the data is relational. I lean towards the backend, where APIs and data models live.

I care about readable code, clean API design, and interfaces that stay fast and accessible. I like owning a feature end to end, from schema to screen.
